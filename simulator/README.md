# BCPU Simulator

The BCPU Simulator will execute Lettuce
instructions without requiring physical hardware.

## Planned components

- CPU state.
- Register file.
- Memory model.
- Instruction decoder.
- Execution engine.
- Debugger.
- Automated tests.

## Supported architectures

- Lettuce32.
- Lettuce32E.
- Lettuce64.

Status: not implemented yet.
