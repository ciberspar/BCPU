# BCPU Agata

Architecture: Lettuce64

Target: high-performance computing.

Planned characteristics:

- 64-bit processor core.
- Initial target: 4 cores and 8 threads.
- L1, L2 and L3 cache design.
- DDR4 memory controller as a future platform goal.
- BGPU Agata integrated graphics as a future project.
- Virtualization and SIMD support.

Status: design phase.
