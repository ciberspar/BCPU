# Lettuce32E ISA

Version: 0.1-draft

Target processor: BCPU Water.

Lettuce32E means Lettuce32 Enhanced.

## Base architecture

Lettuce32E extends the Lettuce32 design.

## Planned enhancements

- Enhanced arithmetic.
- Atomic memory operations.
- Extended SIMD instructions.
- Improved interrupt handling.
- Memory protection extensions.
- Additional system instructions.
- Capability discovery.

## Compatibility

The goal is to execute Lettuce32 programs
on Lettuce32E processors.

## Status

Extensions and instruction encodings are
not finalized.
