# Lettuce64 ISA

Version: 0.1-draft

Target processor: BCPU Agata.

## Basic properties

- Word size: 64 bits.
- 64-bit general-purpose registers.
- Extended memory addressing.
- Little-endian memory model (initial proposal).

## Planned features

- 64-bit arithmetic.
- Advanced memory management.
- Privilege levels.
- Atomic operations.
- SIMD extensions.
- Virtualization support.
- Hardware security features.

## Compatibility

A compatibility mechanism for Lettuce32
software will be designed.

## Status

Lettuce64 is under architectural design.
