# BCPU

**Baco Processing Unit**

BCPU is an experimental processor family based on the
original Lettuce instruction set architecture.

## Processor family

| Processor | Architecture | Target |
|---|---|---|
| BCPU Tomato | Lettuce32 | Low-resource systems |
| BCPU Water | Lettuce64 | Mid-range systems |
| BCPU Agata | Lettuce64AA | High-performance systems |

## Main projects

- Lettuce ISA: processor instruction architecture.
- BCPU Core: processor core implementations.
- BCPU Simulator: software processor simulation.
- BCPU Assembler: future Lettuce assembler.
- BCPU Compiler: future compiler toolchain.
- QEMU Support: future QEMU architecture integration.

## Development status

Experimental project. The architecture is under design.
No physical processor has been manufactured yet.

## Development principles

- Original architecture.
- Documented instruction sets.
- Modular processor designs.
- Open development.
- Simulation before hardware manufacturing.
